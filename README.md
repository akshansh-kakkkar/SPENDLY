# SPENDLY
## Description 
A modern and minimal expense tracking web app to manage daily spending, visualize financial habits, and stay in control of your money.
## Features 
● Set Budget
● Edit Budget
● Local Storage
● Data filtering
● Search functions 
● Stats bar
● add spends
● remove spends
● edit spends 
● Graph
● Pie chart

## Tech Stack
● React
● TailwindCss
● Css
● Recharts
